01 Guardrails workshop

An allergen tagger that is only allowed to add warnings

Menu Decoder

Problem
A 1.5B model I fine-tuned to tag 14 allergens called a dish safe when it was not 7.3% of the time, and never flagged sulphites.
Built
Two layers behind it that can raise a warning but never lower one: a 541-word ingredient lexicon, then a Claude Haiku second opinion on whatever is still unflagged, schema-validated with a retry.
Result
Held-out false-safe 7.3% to 0.8%; hidden allergens missed on 60 adversarial dishes, frozen before the run, 22 to 0. The Haiku layer costs $0.18 per 1,000 dishes.
Failure
Over-warning rises to 27% on the adversarial set, and one of three Haiku runs cleared hummus of sesame.
Next
Human labels on the 840-row sheet in the repo, then distill Haiku's flags back into the small model.

02 Judge evaluation language

Testing the fact-checkers on lines broken on purpose

Podcastify

Problem
Every line of a generated podcast cites its source sentences and is checked before it is voiced, but my old sample had one failure in 20, so it could not measure misses.
Built
A frozen set of 124 lines, 56 of them broken by code (a flipped negation, a moved number, a swapped name), so the right answer is known without labeling. Eight judge runs across Haiku, Sonnet and Opus, plus the local checks.
Result
Opus caught 56 of 56 broken lines in both runs; my pipeline's Sonnet checker caught 44 to 49, missing only negations. A majority vote did worse than Opus alone.
Failure
A JSON parser bug had left 33 lines unchecked on one run; fixed. An earlier page called a model's reading a hand check; corrected with a dated note.
Next
Subtler model-written breaks, human labels, and a Haiku-then-Opus cascade.
  • LLM judge
  • Cohen's kappa
  • Grounding
  • Span viewer

03 Structured output road

A plan agent that kept stretching 10-week plans to 18

Marathon Training Agent

Problem
My LangGraph planner's critique-and-revise loop drifted: an 18-week plan for a runner with 10 weeks, and two different fitness reads for the same runner.
Built
A pydantic plan schema with typed sessions for every day, code checks for what a schema cannot express (week count, race week, phases), errors sent back for up to two repairs, and the fitness read moved from the model to a Riegel calculation. The checks are also an MCP server.
Result
On six runners frozen before the run: 6 of 6 plans pass every check against 1 of 6, no wrong lengths against 3, at $0.10 instead of $0.22 a plan and 47 s instead of 114 s.
Failure
Four of six first drafts broke my own 120-character note limit, which caused most of the repairs. Six runners and one run each shows the failure going away, not a pass rate.
Next
Validate the Riegel read on real race pairs and add back a check on long-run share.

  • Agent
  • MCP server
  • Code checks

04 Agent and MCP workshop

A retirement agent that is not allowed to do arithmetic

When Can I Retire?

Problem
People ask retirement questions in sentences, and a bare model answers them with numbers it made up.
Built
Claude fills a validated JSON scenario, code runs my 152-year simulation engine, and the reply is rejected if it holds any number the engine did not produce. The engine is also an MCP server.
Result
28 of 30 frozen questions right end to end; the headline answer matched the engine on 19 of 20, against 3 of 20 for the bare model, with 1 unsourced number in 300 against 127 in 289. $0.009 and 7.7 s a question.
Failure
One reply dropped the what-if result entirely; my check passes it, because nothing was invented.
Next
A check that every headline value appears in the reply, and human labels for the expected scenarios.
  • Structured output
  • Tool use
  • MCP server
  • Unsourced-number check

05 RAG and in-browser search cellar

Reading 'under twenty bucks' out of the sentence before ranking

Wine Sommelier RAG

Problem
My hybrid retriever ignored plain-English limits: on 28 frozen requests, 77.5% of top-ten results broke a stated price, place or grape.
Built
A pydantic schema Claude fills, checked against the index's own vocabulary with one repair, applied as filters before dense, BM25 and reranking. The same search also runs in your browser on a self-hosted MiniLM.
Result
Limit-breaking results 77.5% to 0 with Sonnet ($0.05 a request) and 1.2% with Haiku ($0.003). The browser index matches the Python retriever on 8.8 of the top 10.
Failure
A regex extractor tied Sonnet, but I wrote both the rules and the requests; the 'not oaky' filter drops unoaked Chardonnays.
Next
Requests written by someone else, and wiring extraction into the command line.
  • RAG
  • Structured output

06 Agent self-critique cellar

A self-critique that never passed, rebuilt as a rubric

Wine Pairing Agent

Problem
My LangGraph pairing agent rejected all 12 of its own drafts, mostly for wines it judged too old as of 2026.
Built
A seven-criterion rubric: three checked in code, four graded by the model as schema-validated JSON, with the pass decided in code. Every run is saved and replayable node by node.
Result
10 of 10 frozen dishes pass, every first pick an accepted grape against 3 of 10 for plain search. Cost $1.25 to $0.49 and time 78 s to 34 s per pairing. It rejected 6 of 6 deliberately mismatched drafts.
Failure
A second judge on Sonnet agreed on only 6 of 10 verdicts (kappa 0.20), and caught a reply telling a guest about 'the Sancerre style you're after'.
Next
Human labels from the sheet in the repo, and a code check for claims against the cited review.

Data stories

Wine Score Inflation cellar

The 100-point wine scale is an 8-point scale

Across about 120,000 unique professional reviews (the source file repeats 9,983) nothing scores below 80, and 85% land between 84 and 92. Some critics are simply more generous than others.

Hitting the Wall road

Predicting the wall from the first few splits

A model trained on 176,059 Boston finishers from 2014 to 2023 reads your splits as you pass each mat and gives a finish range and the chance of hitting the wall. On the unseen 2024 race it missed by 7.9 minutes at halfway, against 18.1 for even pace.

Are Song Lyrics Getting Simpler? language

Song lyrics got longer, not simpler

Fifty years of Billboard hits doubled in length and grew more repetitive, while the vocabulary stayed about where it was.
